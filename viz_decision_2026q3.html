02026-09-16：配分を収入に連動させる（いま 20/25/55）

本人の見立てを「株14%（実績どおり）・金は決められない・順序リスクは許容・収入（月50万）は止まる／続く／増えるのどれもあり得る」と確認し、 目標配分を固定値でなくアプリ収入の状態で1段ずつ動かす形に変えた。ゴールドは常に 25〜30、動かすのはレバナス ⇄ 無レバ株式のみ。

  • 理由1：株14%の世界では金の見立ては下限割れに効かない（金0〜12%で 0.2〜1.5%）。効くのは株の見立てが外れたときだけ → 金は保険として 25〜30 固定
  • 理由2：収入が続く限りどの配分も下限割れ≈0%。差が出るのは収入停止時と株の見立て外れだけ → レバナスの量を収入で決める
  • 運用：境界（12万・37万・75万）を跨いだら翌月に1段だけ。増収側は半年待つ。収入停止時は 0/30/70（本人選択。10/25/65 は1段悪い）

出発点（2026年6月）はレバナスが資産の半分以上・ゴールド11%・現金と債券ほぼゼロ。 暫定案 33/34/33 を経て、レバナスを大きく削り株を厚くした 15/25/60 に決め、 同日、金の期待リターン信念を8.5%へ引き上げたことに伴い 15/30/55 へ再調整した（レバ15は不変）。 個別株・仮想通貨・iDeCo はこの3枠の外（独立枠）。

2なぜそう決めたか（要点3つ）

  • レバナス 33 → 15：既存の全シミュレーションにレバナスの調達コスト（先物の金利負担・年1.7〜4%）が未計上だった。課すとレバ33の成長優位が消え、効率の膝はレバ10〜15へ動く。0にしなかったのは本人の成長選好（中央値+4〜6% を下限割れ +1pt弱 で買う）。 → 説明と表は 入口ページ FAQ「なぜ2倍レバレッジが要るの？」
  • ゴールド 25 → 30：金の期待リターンを株と同じ規則「実績とCMAの中間」で 8.5% と置いた。その前提では金30が悲観・株弱気の両方で下限割れ・中央値とも優位。負けるのは金の前提が全部外れる複合最悪のみ。 → 入口ページ FAQ「なぜゴールドが30%もあるの？」／見立て別の行き先は 早見表
  • 債券なし・為替ヘッジなし：米国長期債は「ゴールドより良い守り」ではなく「金の見立てが外れたときの保険」（2026-09-04 検証）。為替ヘッジは年2.7%のコストに対し守りがほぼ増えない。 → 入口ページ FAQ「債券」「為替」

当時の全記録は docs/配分見直し2026-07-09.md、エンジンは analysis/withdrawal_sim50_2026q3.py。 決定当時の数表（月50万→40万の崖型・収入なし）は git 履歴にある。

3移行プラン（現状 → 15/30/55）

  1. 売却：為替ヘッジありレバナス全額（auAM＋iFree＝目論見書でフルヘッジ確認）／Zテック20（NISA=無税）／USA360／無ヘッジレバナスを15%まで薄くトリム
  2. 買付：ゴールドを厚めに（低コスト品＝314A 0.22%・SBIゴールドF 0.15〜0.18%）／NASDAQ100無レバも買付（新規はすべてこちら）
  3. SP500は売らない（含み益が大きい）＝無レバ株式枠に算入し保有継続。FANG+はNISA枠内で数年かけNASDAQ100へ置換（税0）
  4. 個別株・仮想通貨・DCは不可触

移行の一回限り税は総資産の約3.8%うち大半はヘッジあり→なし変換。 変換分は年約0.9%のキャリー・信託報酬漏れの解消で約5年で回収。リバランスは±10ptの帯＋取り崩しを 超過枠から充当（毎年きっちり戻すと50年で税が数億円の空回り）。15/25/60からの追加調整（金5%分の 追加買付）自体の税負担はごく小さい。
